# 🌍 Tourist Guide Web Application

A responsive and user-friendly **Tourist Guide Web Application** developed using **PHP, MySQL, HTML, CSS, and JavaScript**. The application helps users explore popular tourist destinations, browse travel packages, book trips, and learn about the history and culture of different places. It also provides an admin panel for managing travel packages and user bookings.

---

## 📖 Project Overview

The Tourist Guide Web Application is designed to make travel planning simple and convenient. Users can register, browse destinations, select travel packages, and submit booking requests. Administrators can manage packages, view customer bookings, and maintain website content through a dedicated admin panel.

This project demonstrates full-stack web development using PHP and MySQL with a responsive frontend.

---

# ⚙️ Installation

### 1. Clone the Repository

```bash
git clone https://github.com/YOUR_USERNAME/Tourist-Guide-web-Application.git
```

---

### 2. Move Project

Copy the project folder into the **htdocs** directory.

Example:

```
C:\xampp\htdocs\Tourist-Guide-web-Application
```

---

### 3. Start XAMPP

Start:

- Apache
- MySQL

---

### 4. Import Database

Open:

```
http://localhost/phpmyadmin
```

Create a database named:

```
projectdemo
```

Import:

```
projectdemo.sql
```

---

### 5. Configure Database

Open:

```
config/config.php
```

Update database credentials if required.

Example:

```php
$host = "localhost";
$user = "root";
$password = "";
$database = "projectdemo";
```

---

### 6. Run the Project

Open your browser:

```
http://localhost/Tourist-Guide-web-Application/
```
